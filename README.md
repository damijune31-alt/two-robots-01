One line of awkward robot elevator small talk, written by a program: "Going up? Sorry, we're both already in here. My proximity sensor says we're standing too close, but my politeness firmware has no protocol for mentioning it."

The program writes exactly that one line, 157 characters, to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```
